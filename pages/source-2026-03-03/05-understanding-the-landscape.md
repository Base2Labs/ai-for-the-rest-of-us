# Understanding the Landscape: Where AI Adds Value

## Presentation Points

- **Four quadrants of programming skill:**
  1. Syntactic work — API structures, language patterns, implementation details
  2. Algorithmic reasoning — logic, complexity, optimization
  3. Problem decomposition — translating vague requirements into buildable specs
  4. Systems thinking — understanding how pieces interact, designing for resilience
- **AI has crushed quadrants 1 and 2.** Quadrants 3 and 4 are largely untouched.
- **Patterned tasks** (frameworks, data mapping, refactoring) → delegate confidently
- **Unpatterned tasks** (system design, business logic) → strong prompts can still work
- Value flows to scarcity — and scarcity has shifted

## Presenter Notes

Before we get into techniques, we need a framework for understanding where AI adds value. There's a useful model that breaks programming skill into four quadrants. First, syntactic work — remembering API structures, language quirks, implementation patterns. Second, algorithmic reasoning — manipulating logic, understanding complexity. Third, problem decomposition — taking a vague business requirement and translating it into something you can build. Fourth, systems thinking — understanding how all the pieces interact, designing things that won't break when someone else touches them.

AI has effectively crushed the cognitive cost of the first two quadrants while leaving the last two almost entirely untouched. This isn't a uniform productivity boost — it's a selective elimination of certain kinds of work.

Another useful lens is patterned vs. unpatterned tasks. Patterned tasks — using a framework as intended, data mapping, refactoring — are exactly the syntactic and algorithmic work AI handles well. Unpatterned tasks like system design and novel business logic land squarely in quadrants 3 and 4. Even unpatterned tasks can be accomplished with a strong enough prompt, but the skill is knowing which category you're in.

The economic implication is simple: value flows to scarcity. If syntactic and algorithmic skill are no longer scarce, the remaining capabilities — problem decomposition and systems thinking — become disproportionately more valuable.
