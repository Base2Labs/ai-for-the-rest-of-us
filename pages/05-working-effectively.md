# Working with it well

---

# You're not writing prompts — you're managing a transcript

Reframe the whole act: every technique here is about what occupies the window and what doesn't.

---

# Plan first, execute second

Keep the thinking in one place and the doing in another, so the planning never eats the room the work needs.

---

# Start over more often than feels natural

Sessions drift, stale context poisons output, and closing one is cheaper than fighting it.

---

# Don't hand it everything — tell it what exists

Describe what's available and let it ask for what it needs, instead of dumping the whole pile in up front.

---

# Consistency in, consistency out

Your conventions are an implicit prompt: a tidy codebase steers the model whether you meant it to or not.

---

# Script the parts that repeat

Anywhere a script can replace a model call, it should — same answer every time, and free.

---

# Which model should I use?

The only version of the parameters-and-tuning question that matters in practice: big for judgment, small and cheap for volume.

---

# Same model, very different results

The tool wraps the model in a system prompt you never see, and that wrapper changes the output as much as the model does.

---

# The 17% problem

A controlled study found the AI-assisted group scored 17% lower on mastery — with one exception, and the exception is the whole lesson.

---

# The roadmap that teaches you

A learning technique that inverts the obvious one: don't ask it to write the document and then read it.

---

# Writing it up is how you advance

Teach in chat, get quizzed, ask your own questions — then the document falls out as a byproduct, capturing the questions you actually asked.
